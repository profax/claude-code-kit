# image-preview

Hover a pasted `[Image #N]` to see the picture: above the prompt while you
write, and on the prompts you already sent. Click to open it in the system
viewer.

```
/plugin install image-preview --marketplace profax/claude-code-kit
```

It needs the fullscreen interface (`/tui fullscreen`), and on Linux
ImageMagick. How each terminal draws the picture is described in the
[claude-code-kit README](https://github.com/profax/claude-code-kit#image-preview).
