# quick-peek

Paths in Claude's replies become links. Hover one for a card with the file's
size, age and first lines; click to show it in the file manager, Alt-click to
open it.

```
/plugin install quick-peek --marketplace profax/claude-code-kit
```

It needs Claude Code 2.1.325 or later and its fullscreen interface (`/tui
fullscreen`). The [claude-code-kit README](https://github.com/profax/claude-code-kit#quick-peek)
describes it in full and lists its
[known limitations](https://github.com/profax/claude-code-kit#known-limitations).
